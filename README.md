# project-execution-protocol-skill

Публичный репозиторий со скиллом `project-execution-protocol` для Codex.

## Структура

- `skills/project-execution-protocol/SKILL.md`
- `skills/project-execution-protocol/agents/openai.yaml`
- `skills/project-execution-protocol/LICENSE.txt`

## Установка скилла

Через URL папки скилла:

```bash
$skill-installer install https://github.com/clunkyharp/project-execution-protocol-skill/tree/main/skills/project-execution-protocol
```

После установки перезапусти Codex.

## Альтернатива (через repo/path)

```bash
python3 ~/.codex/skills/.system/skill-installer/scripts/install-skill-from-github.py \
  --repo clunkyharp/project-execution-protocol-skill \
  --path skills/project-execution-protocol
```
